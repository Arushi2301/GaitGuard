# GaitGuard

GaitGuard is a smartphone app that screens athletes for injury-risk movement patterns. The athlete records a short video of a movement, pose estimation (MediaPipe) tracks body landmarks, and the resulting joint angles are compared against published sports-science thresholds to give a plain-language screening result.

GaitGuard is a screening tool, not a medical diagnosis.

For the pose analysis API setup and JSON contract, see [backend/README.md](backend/README.md).
